# Sudoku.com (com.easybrain.sudoku.android v7.7.0) — 13 min/year (barely used)

Screens: `shots/k01`–`k06` (mostly ads/pop-ups: full-screen ad on open, a "SKIP" that opened the
Play Store, then a chain of event pop-ups before reaching the menu).

Build a clean classic Sudoku with the standard Sudoku.com feature set (public knowledge):
- Difficulties: Easy, Medium, Hard, Expert (+ Master/Extreme optional). Unique-solution puzzles.
- Number pad 1–9 with remaining counts; Undo, Erase, Notes (pencil) toggle, Hint.
- Mistake limit (3, toggleable), timer, highlight same numbers / row / column / box, auto-remove notes.
- Stats per difficulty: games, wins, best time, average time, streaks. Daily challenge calendar optional.
- No ads, no events, no pop-ups.
